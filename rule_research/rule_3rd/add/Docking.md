1. Docking简短规格只适用于Commercial, Consumer, SMB产品线.
2. Docking取值自HTML Spec的Docking, 取值规则是:
2.1 "Various docking"开头的条目, "Various docking"替换为"Docking".
2.2 "For more compatible"开头的条目, 整句话删除.
2.3 其他条目原样取值.
2.4 如果存在两个条目:
"Chromebook folio keyboard with touchpad (Pogo pin, detachable)"和"No keyboard docking inbox", 则输出"Chromebook folio keyboard with touchpad (Pogo pin, detachable)*"
3. 若HTML Spec不包含Docking信息, 则不生成Chipset简短规格.
